# Documentation Summary

**QLBanHang** — phần mềm quản lý báo giá, khách hàng, hàng hóa, dashboard và báo cáo doanh thu theo nhân viên kinh doanh. Backend dùng .NET 9 Clean Architecture + EF Core/Npgsql/PostgreSQL; frontend dùng React 18 + Vite + TypeScript + TanStack Query/Table.

## Architecture

System design, component interactions, data flows, deployment, and external integrations.

| File | Description |
| ---- | ----------- |
| [architecture/system-architecture.md](architecture/system-architecture.md) | Clean Architecture layering, auth/refresh-token flow, RBAC/permission matrix, quotation ownership, dashboard/report/export flow (including the TT133 report form exports, branch/company report scope and the company profile, and the payment QR on receipts and stock-outs: the screen and print flow through `VoucherPaymentQrService`, the access rules and the bank fields of a fund), the executive dashboard (metrics services, scope, routes and permissions, which figures are tested against which report, the real-time `DashboardChanged` SignalR signal), demo branches and sample data (create flow through the queue, worker, runner and business services, acting identity, status and start-up recovery, hard delete order and sample catalog cleanup, company scope excluding demo branches, one dashboard signal per seed), the `activeOnly` option of the two partner search endpoints and the quick add grants of the Accountant and Warehouse roles plus `products.create` for Warehouse, Accountant and Sales (product quick add), API response, soft-delete/audit, migration/seed, logging and frontend layering |
